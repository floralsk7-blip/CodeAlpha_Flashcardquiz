# Flashcard Quiz App

A simple flashcard app for studying, built as part of the CodeAlpha App Development internship (Task 1).

## Features

- Question on the front, answer on the back, with a "Show Answer" button
- Next and Previous buttons to move between cards
- Add, edit and delete your own flashcards
- Cards are saved in the browser (localStorage), so they stay after a refresh
- Simple, clean layout that works on phones and computers

## Technologies Used

- HTML for the page structure
- CSS for the styling and layout
- JavaScript for the app logic

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.

## Project Structure

- `index.html`: the page
- `style.css`: the styling
- `java.js`: the app logic

## What I Learned

- Storing data in an array and redrawing the screen from it
- Handling button clicks with JavaScript functions
- Saving data with localStorage
- Styling with CSS (flexbox and grid)
